# 매일 영어회화 (안드로이드 앱)

일상 회화·응대 영어 표현을 듣고, 말하고, **말하기 채점**까지 받는 개인용 영어 공부 앱입니다.

- 주제 11개 (일상 6 · 응대 5, 길 안내하기 포함) / 표현 100개 / 주제별 롤플레이
- 🔊 원어민 발음 듣기 (속도 조절)
- 🎤 말하기 채점: 단어별로 맞힌 단어(초록)·빠진 단어(빨강) 표시 + 점수
- 카드 연습, 즐겨찾기, 외운 표현 기록

## APK 받는 방법 (GitHub 자동 빌드)

1. GitHub에서 새 저장소를 만듭니다 (예: `daily-english`).
2. 이 폴더의 파일을 **전부** 올립니다. (`node_modules` 폴더는 없어도 됩니다.)
   - `.github` 폴더가 꼭 같이 올라가야 자동 빌드가 됩니다.
3. 저장소의 **Actions** 탭에서 "APK 빌드"가 끝날 때까지 기다립니다 (약 5~8분).
4. 저장소의 **Releases → 매일 영어회화 최신 버전**에서 `daily-english.apk`를 휴대폰으로 내려받습니다.
5. 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 한 번 켜 줍니다.
6. 처음 🎤를 누르면 **마이크 권한 허용**을 눌러 주세요.

## 내용 고치기

표현·대화문은 `www/index.html` 안의 `DATA` 부분에 있습니다.
고친 파일을 다시 올리면 Actions가 새 APK를 자동으로 만듭니다.

## 참고

- 음성 인식은 휴대폰의 Google 음성 인식을 사용합니다 (인터넷 연결 필요).
- 휴대폰에 영어 음성이 없으면 설정 → 텍스트 음성 변환(TTS)에서 영어(미국)를 추가하세요.
